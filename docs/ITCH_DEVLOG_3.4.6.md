# Constellore 3.4.6 - One Tap to the Stars

Play now means play.

## One tap starts the next challenge

The main **Play** button no longer sends you through another choice screen or a long mission summary. It immediately closes the Cosmic Gate, shows a short thought while the next challenge is prepared, and opens directly onto the game.

This same arrival is used whether the next challenge is a word journey or one of Constellore's occasional Star Breaks.

## The objective appears where it matters

Once the new board is visible, a small card explains only what you need to do:

- the goal;
- one short instruction;
- any limit that can end the challenge;
- one **Start** button.

Scoring, moves, and timers wait for Start, so reading the objective never costs the player anything. The old reward, rule, route, and scoring panels have been removed from this moment.

## Less menu, more game

The home screen still offers alternate ways to play for players who want them, but the main path is now deliberately simple: **Play → Cosmic Gate → objective → game**.

The itch.io HTML5 build remains deterministic local practice. It does not currently include live accounts, shared leaderboards, payments, or live AI. Progress is stored in your browser on this device and may reset during beta development.

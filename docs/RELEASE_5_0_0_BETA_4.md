# Constellore 5.0.0-beta.4 publication

This release brings the current cinematic website and integrated game to GitHub Pages.

## Included

- Three website chapters, interactive universe preview, current game captures, Cosmetic Lab previews, readable responsive navigation, and accessible policy pages.
- Direct Home entry without the old first-open intro, improved Earth presentation, the rebuilt combining board, and the Spatial Bloom word selector.
- Mobile Moon, Outpost, and Heart project layout fixes; account-recovery preservation; Arena layout, cancellation, reconnect, and forfeit fixes.
- Complete static startup dependencies in the offline cache and a usable Home fallback when the optional planet renderer is unavailable.
- Deterministic release transforms within the existing download budgets, LF source checkouts, and the Python/NumPy prerequisites used by CI audio tests.

## Verification

The publication pass exercised desktop and mobile new-player completion, reload recovery, accessibility, readable text, responsive Home layouts, and PWA startup. It also completed Earth + Water to Mud after warming the board online and reloading offline. The exact static artifact passes packaging and performance checks. Private browser profiles, account diagnostics, original birthday media, and raw Blender authoring files remain outside the commit.

## Scope still under audit

GitHub Pages serves the portable local-practice game. Live matchmaking needs a separately configured hosted duel backend. First-ever offline Play cannot load gameplay modules that have never been cached. General save import and the in-game cosmetic board preview remain follow-up audit items. This publication is not a claim that the full game audit is complete.

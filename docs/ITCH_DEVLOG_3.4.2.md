# Constellore 3.4.2 — The Cosmos Comes Into Focus

The Cosmic Gate is now sharper, more responsive, and better framed on every kind of screen.

## Artwork made for the screen

Constellore previously stretched one 1088px gate image across phones, tablets, desktop monitors, and high-resolution displays. This patch replaces that one-size-fits-all source with three purpose-built responsive assets:

- a portrait composition for phones and tall screens;
- a 1080p landscape image for ordinary computers and tablets;
- a 4K-sized landscape image for large or high-density displays.

The browser selects the source suited to the current screen, so smaller devices avoid carrying the largest artwork while high-resolution displays receive the detail they can actually show.

## A steadier home cosmos

The home panorama is now anchored to the viewport rather than stretched by the height of the page content. The stars and central gate remain one continuous scene while menus grow, overlays open, or the page scrolls.

This is a visual patch. Challenge rules, progression, saved results, the branching Show Answer sequence, and the safe result exit introduced in the previous update remain unchanged.

Thank you for helping make Constellore clearer and more beautiful on every device.

## Beta note

The itch.io HTML5 build is deterministic local practice. It does not currently include live accounts, shared leaderboards, payments, or live AI. Progress is stored in your browser on this device and may reset during beta development.

# Constellore 3.4.1 — Results Stay With You

This small but important patch makes the end of every challenge safer and easier to understand.

## What changed

- **A close button that stays available.** The completed-game panel now has a clear close control fixed near its top, so you can always find the way back even after scrolling through a long result.
- **One reliable way home.** Closing the result now follows the same complete **Return home** flow as the main result action. It cleans up the finished game and returns to the menu instead of only hiding the window.
- **Pending scores remain visible.** If a verified score is still waiting to be saved, the result panel stays open until it is safe to leave. Pending progress can no longer disappear behind a closed result.

The Cosmic Gate, branching Show Answer animation, private challenge matching, Route Ranks, and every update from the previous release remain unchanged.

Thank you to everyone testing the beta and reporting the small moments that interrupt play. Those details matter.

## Beta note

The itch.io HTML5 build is deterministic local practice. It does not currently include live accounts, shared leaderboards, payments, or live AI. Progress is stored in your browser on this device and may reset during beta development.

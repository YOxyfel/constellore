# Your ideas can reach us — Update 3.5.1

Constellore already asked a short question when two words felt like they should combine. The game could safely save that answer on your device, but the public build did not yet have a free receiver.

This update completes that missing connection.

## Beta 5 play polish

Successful combinations now build a small cumulative story scene on the word board. The first discovery becomes its foundation, later discoveries add visual layers according to their role, and a wrong pair crumbles then restores the valid scene without removing gameplay progress.

Star Trail is now a real memory round: it starts with three stars, scales to four and five, reveals the numbered order for exactly five seconds with input locked, then removes every answer cue before recall. Used hints remain visible as a Current Hint objective, completed games no longer expose a starting-word selector, and the Silver home catalog has been reduced to a clearly secondary section.

Quit returns Home in one click. Master-volume decrease, percentage, and increase controls remain visible throughout word levels, Pause, and Cosmos Circuit, while Music and Effects stay available in the adjacent mixer.

## One tap, no account

The public game can now send a missing-combination idea directly to Oxyfel Games without opening GitHub. It asks for no name, email address, login, or open comment.

Only the two words, an optional short answer, one reason, the game mode, and a random duplicate-check value are accepted. Unknown words, links, oversized text, and combinations that already have an authored answer are rejected.

## Offline still works

Every idea is still saved locally first. If the receiver is temporarily unavailable, the game keeps a small retry queue and sends again after the connection returns. It never pretends an idea arrived when it did not.

## Built for privacy

The receiver stores no raw player identifier or IP address. Duplicate-check values become pair-specific one-way digests, reports contain no contact details, and inactive report rows expire automatically.

This is quiet infrastructure rather than a flashy new mode, but it matters: when a connection feels obviously missing, your input can now become part of making Constellore's authored universe better.

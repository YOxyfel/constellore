# Constellore 3.3 — itch.io page description

## Short description

Combine words on a cosmic board, discover new ideas, and build a path to the target.

## Full description

**Can you make the target word?**

Every game shows you one word to find. Start with a small set of useful words, then drag two together to discover something new:

**Earth + Water = Mud**

Use each new word to keep building until one final combination makes the target. Every challenge is checked to make sure it can be reached from the exact starting words you receive.

### A puzzle that grows with you

- **500 reachable target words** and **3,199 hand-built combinations**
- **One Play button** that chooses a suitable challenge and starting mix
- **12 permanent Route Ranks** with best-of-three promotion games
- **Route Remixes** that gradually introduce waypoints, blocked shortcuts, special rules, and longer chains
- A playful **Run IQ** score, from 0 to 200, that rewards useful combinations and accurate streaks
- **Six evolving board skies**, from a quiet Bronze night to a climactic cosmic singularity
- Relaxed, timed, limited-move, Daily, Weekly, and free-exploration play

Constellore begins with familiar words and simple routes. As you get better, it introduces fresh starting words, longer paths, and new twists. If a challenge is too hard, the next one can become gentler. A rank you earn is never taken away.

Run IQ is a game score for each puzzle, not a real intelligence test.

Play with touch, mouse, or keyboard. No account is needed.

### Beta note

The itch.io HTML5 version is deterministic local practice. Progress is stored in your browser on this device and may reset during beta development. This build does not currently include live accounts, shared leaderboards, payments, advertisements, or live AI.
